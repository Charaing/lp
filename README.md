# lp

앨범을 폴더에 넣으면 앨범마다 다른 LP가 만들어지고, 턴테이블에 올려 들을 수 있는 웹 페이지예요.

**사이트:** https://charaing.github.io/lp/

## 앨범 넣기

`albums/` 아래에 앨범마다 폴더를 하나 만들고 표지와 노래를 넣은 뒤 `main`에 푸시하세요. 몇 분 뒤 사이트에 나타나요.

```
albums/
└─ 내 앨범/
   ├─ cover.jpg          표지 (jpg, png, webp — 없어도 됨)
   ├─ 01 첫 곡.mp3       노래 (mp3, m4a, ogg, wav, flac)
   ├─ 02 두 번째 곡.mp3
   └─ album.json         선택 사항
```

- 트랙 순서는 파일 이름 순서예요(`2`가 `10`보다 먼저). 앞의 번호와 확장자를 뺀 나머지가 곡 제목이 돼요.
- 노래 파일이 없는 폴더는 건너뛰어요.
- LP 색과 무늬는 표지에서 자동으로 정해져요. 같은 앨범은 항상 같은 LP가 나와요.

### album.json (선택)

```json
{
  "title": "앨범 제목",
  "artist": "아티스트",
  "year": 2026,
  "vinyl": { "color": "#c0392b", "style": "marble", "accent": "#f5d76e" },
  "label": { "color": "#111111", "text": "#ffffff" },
  "rpm": 33
}
```

| 항목 | 설명 |
|---|---|
| `title` | 없으면 폴더 이름 |
| `vinyl.style` | `solid`, `translucent`(반투명), `marble`(마블), `splatter`(물감 튄 무늬), `picture`(표지가 인쇄된 픽처 디스크) |
| `vinyl.color`, `vinyl.accent` | 비닐 바탕색과 무늬 색 (`#rrggbb`) |
| `label.color`, `label.text` | 표지가 없을 때 가운데 라벨 색과 글자 색 |
| `rpm` | 33 또는 45. 처음 선택될 회전 속도 |

## 조작

- 왼쪽(휴대폰에서는 아래)에서 레코드를 고르면 플래터에 올라가요.
- **시작**을 누르고 톤암을 레코드 위로 끌어다 놓으면, 바늘 아래에 있는 곡이 처음부터 재생돼요. 바깥쪽이 1번 곡이고, 곡 사이의 굵은 홈이 곡 경계예요. 라벨 가까이 안쪽 끝에 놓으면 런아웃 홈이라 소리가 나지 않아요.
- **정지**를 누르면 멈추고, 톤암을 거치대로 돌려놓으면 바늘이 들려요.
- 키보드: `Space` 재생/정지, `←` `→` 이전/다음 곡.
- 아이폰: Safari 공유 버튼 → **홈 화면에 추가**로 앱처럼 쓸 수 있어요. 재생 중에는 잠금 화면과 다이내믹 아일랜드에 곡 제목·아티스트·앨범 표지가 뜨고, 거기서 재생/정지와 이전/다음 곡도 돼요.

## 데모 앨범

예시 앨범이 필요하면 `npm run demo`를 실행하세요. 직접 합성한 소리와 그림으로 `albums/demo-*` 앨범 세 개를 만들어요.

## 내 컴퓨터에서 보기

Node 22 이상이 필요해요.

```bash
npm run build
```

```bash
npm run serve
```

그다음 http://localhost:8080 을 여세요. 테스트는 `npm test`로 실행해요.
