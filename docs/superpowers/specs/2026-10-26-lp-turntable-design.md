# LP 턴테이블 — 디자인 스펙

- 날짜: 2026-10-26
- 상태: 사용자 검토 대기

## 1. 목적

저장소의 `albums/` 폴더에 앨범(표지 + 노래)을 넣고 푸시하면, 공개 웹사이트에서 그 앨범이
**앨범마다 다르게 생긴 LP**로 나타나고, 턴테이블을 직접 조작해 들을 수 있는 체험형 웹 "게임".

### 성공 기준

1. 새 앨범 폴더를 추가하고 푸시하면, 다른 파일을 손대지 않아도 몇 분 안에 사이트에 LP가 나타난다.
2. 앨범마다 LP의 비닐 색·스타일·라벨이 눈에 띄게 다르다(표지에서 자동 생성, `album.json`으로 덮어쓰기 가능).
3. 톤암을 끌어 레코드에 올리면 재생되고, 바늘 위치로 트랙 선택/탐색이 된다.
4. 결과물은 GitHub 저장소 `Charaing/lp`(공개)에 있고 GitHub Pages 링크로 접속된다.

### 범위 밖 (YAGNI)

점수/레벨, 로그인, 브라우저 업로드, 서버, 재생목록 저장, 스크래치 효과음 게임 요소.

## 2. 사용자가 말한 것 vs 가정

| 구분 | 내용 |
|---|---|
| 요청 | 폴더에 앨범·표지·노래 → 들을 수 있음, 앨범마다 다른 LP, 새 저장소 `lp`에 게시, 링크 공유 |
| 선택 | 저장소 폴더 방식 / 턴테이블 조작 체험(점수 없음) / LP 자동 + 선택 설정 / 1안(Actions가 목록 생성) |
| 가정 | 저작권 문제로 상용 음원 미포함 — 직접 합성한 데모 앨범 2~3개 포함. 계정 `Charaing`에 공개 저장소. |

## 3. 아키텍처

빌드 도구 없는 정적 사이트 + 목록 생성 스크립트 + GitHub Actions 배포.

```
lp/
├─ index.html            # 진입점
├─ css/style.css
├─ js/
│  ├─ main.js            # 부트스트랩: albums.json 로드, 컴포넌트 연결
│  ├─ shelf.js           # 레코드 선반 UI
│  ├─ turntable.js       # 플래터 회전, 톤암 드래그, 바늘 ↔ 시간 매핑
│  ├─ player.js          # HTMLAudioElement 래퍼: 트랙 순차 재생, 탐색
│  ├─ vinyl.js           # 캔버스로 LP 그리기 (순수 함수 + 그리기)
│  └─ palette.js         # 표지 색 추출, 시드 난수 (순수 함수)
├─ scripts/
│  ├─ build-manifest.mjs # albums/ 스캔 → albums.json
│  └─ make-demo.mjs      # 데모 앨범 WAV/표지 생성 (1회성)
├─ tests/                # node:test 단위 테스트
├─ albums/<앨범>/...
└─ .github/workflows/pages.yml
```

의존성 없음(Node 20 내장 기능만 사용). `package.json`은 `test`/`build` 스크립트용.

## 4. 앨범 폴더 규칙

```
albums/<폴더명>/
├─ cover.jpg | cover.png | cover.webp   # 선택 (없으면 생성 라벨)
├─ 01 첫곡.mp3                           # mp3, m4a, ogg, wav, flac
├─ 02 둘째곡.mp3
└─ album.json                            # 선택
```

- 트랙 순서: 파일명 자연 정렬(`2` < `10`). 트랙 제목은 파일명에서 앞 번호·구분자·확장자를 뗀 것.
- 오디오 파일이 하나도 없는 폴더는 목록에서 제외(경고 출력).
- `album.json` (모든 필드 선택):

```json
{
  "title": "앨범 제목",
  "artist": "아티스트",
  "year": 2026,
  "vinyl": { "color": "#c0392b", "style": "marble", "accent": "#f5d76e" },
  "label": { "color": "#111111", "text": "#ffffff" },
  "rpm": 33
}
```

- `title` 기본값: 폴더명. `style`: `solid | translucent | marble | splatter | picture`(picture = 표지 이미지를 디스크 전체에 깐 픽처 디스크). `rpm`은 33/45 버튼의 초기값.

## 5. 목록 생성 (`build-manifest.mjs`)

입력 `albums/`, 출력 루트의 `albums.json`:

```json
{ "albums": [ {
  "id": "folder-name",
  "title": "...", "artist": "...", "year": 2026,
  "cover": "albums/folder-name/cover.jpg",
  "tracks": [ { "title": "첫곡", "src": "albums/folder-name/01%20첫곡.mp3" } ],
  "vinyl": { ... }, "label": { ... }, "rpm": 33
} ] }
```

- 경로는 URL 인코딩(공백·한글 대응).
- `album.json`이 잘못된 JSON이면 그 앨범은 기본값으로 진행하고 경고.
- 트랙 길이는 빌드 시 계산하지 않음(브라우저가 `loadedmetadata`로 측정).
- `albums.json`은 커밋하지 않고(`.gitignore`) Actions에서 생성. 로컬 확인은 `npm run build`.

## 6. 배포

`.github/workflows/pages.yml`: `main` 푸시 시 checkout → Node 20 → `npm test` → `node scripts/build-manifest.mjs`
→ `actions/upload-pages-artifact` → `actions/deploy-pages`. 저장소 Pages 소스는 "GitHub Actions".

## 7. 화면과 조작

**레이아웃** (데스크톱): 왼쪽 레코드 선반, 오른쪽 턴테이블. 모바일(≤ 768px): 위 턴테이블, 아래 가로 스크롤 선반.

**미적 방향**: 따뜻한 오디오 가구 느낌 — 월넛 나무 결 바탕, 브러시드 알루미늄 플래터 테두리, 크림색 타이포.
디스플레이 서체 1종(세리프/레트로) + 본문 서체 1종(Google Fonts). 조명은 위에서 비추는 부드러운 하이라이트.

**선반**: 앨범 표지가 크레이트에 기울어져 꽂힌 모습. 마우스를 올리면 살짝 들림 + 슬리브에서 LP 가장자리가 보임.
클릭 → LP가 슬리브에서 빠져 플래터로 이동(애니메이션) → 이전 LP는 선반으로 돌아감.

**턴테이블**:
- 시작/정지 버튼: 플래터 회전(가속·감속 관성). 33/45 버튼은 시각적 회전 속도만 바꿈(재생 속도는 그대로).
- 톤암: 거치대에서 드래그. 레코드 위에서 놓으면 바늘이 내려가며(짧은 지연) 재생 시작.
- 바늘 위치 → 재생 위치: 레코드 바깥 홈 반경 `rOuter`부터 안쪽 `rInner`까지를 앨범 전체 길이에 선형 매핑.
  해당 시간이 속한 트랙의 **처음**으로 이동(2026-10-26 변경: 긴 앨범에서 곡 중간에 떨어지는 문제). 안쪽 끝(런아웃)은 앨범 끝.
  재생 중엔 톤암이 시간에 맞춰 안쪽으로 이동.
- 앨범 끝 도달 → 바늘이 런아웃 홈에 머무르며 정지(무음), 톤암을 거치대로 돌려놓을 수 있음.
- 바늘이 올라가 있지 않거나 플래터가 멈추면 일시정지.
- 키보드: `Space` 재생/일시정지(바늘 자동), `←/→` 이전/다음 트랙. 톤암에 `aria-label`과 슬라이더 역할 부여.
- 정보 패널: 앨범명·아티스트·현재 트랙·경과 시간.

## 8. LP 생성 (`vinyl.js`, `palette.js`)

- 시드 = 앨범 `id`의 해시 → 결정론적 난수(mulberry32). 같은 앨범은 항상 같은 LP.
- 표지 색 추출: 64×64로 축소한 캔버스 픽셀을 양자화(채널당 4비트) 히스토그램 → 채도·빈도 가중 상위 색.
- 스타일 자동 선택(`album.json`에 없을 때): 시드로 `solid/translucent/marble/splatter` 중 선택,
  표지 색이 매우 다채로우면 `picture` 확률 증가.
- 그리기: 기본 비닐 → 스타일 텍스처 → 미세 홈(동심원 노이즈) → 트랙 사이 넓은 무음 홈(트랙 길이 비율)
  → 광택 하이라이트(회전하지 않는 별도 레이어) → 가운데 라벨(표지 원형 크롭 또는 단색 + 제목) → 스핀들 구멍.
- 트랙 길이를 알기 전엔 균등 분할로 그렸다가, 측정 완료 후 다시 그림.
- 정적 LP는 오프스크린 캔버스에 1회 렌더 후 CSS `transform: rotate`로 회전(성능).

## 9. 오류 처리

| 상황 | 동작 |
|---|---|
| `albums.json` 로드 실패/앨범 0개 | 빈 선반 + "albums/ 폴더에 앨범을 넣어주세요" 안내 |
| 표지 없음/로드 실패 | 생성 색상 라벨, 시드 기반 색 |
| 트랙 로드/재생 실패 | 토스트 알림, 다음 트랙으로 건너뜀 |
| 브라우저 자동재생 차단 | 사용자 조작(톤암 놓기)에서만 재생 시작하므로 발생 안 함 |

## 10. 데모 콘텐츠

`make-demo.mjs`로 앨범 3개 생성: 각 2~3트랙, 트랙당 20~30초 모노 22.05kHz WAV(간단한 합성 멜로디),
표지는 Node에서 내장 zlib로 직접 인코딩한 256×256 PNG(그라데이션·도형).
표지 색이 서로 확연히 다르게 해서 LP 자동 생성 차이를 보여줌. README에 데모 삭제·교체 방법 명시.

## 11. 테스트

- 단위(`node --test`): 파일명 → 트랙 제목/자연 정렬, 목록 생성(임시 폴더 픽스처), 잘못된 `album.json` 처리,
  URL 인코딩, 바늘 반경 ↔ (트랙, 오프셋) 매핑, 시드 난수 결정성, 색 양자화.
- 수동/브라우저: 로컬 정적 서버로 열어 선반 선택 → LP 이동 → 톤암 드래그 재생 → 탐색 → 모바일 폭 확인.
- 배포 후 Pages URL에서 앨범 로드와 재생 확인.
